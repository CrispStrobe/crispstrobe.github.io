# Brickwright Pages compatibility

This account site keeps public editor links available during the Brickwright repository transition. The two application repositories continue to build and publish their own editors.

The old `/brickwright-lite/` entry moves to the active editor on the same origin once the new project publishes its identity marker. `/brickwright/editor.html` leads to the Legacy editor. When a project site is unavailable, this site links to its separate Vercel deployment.
